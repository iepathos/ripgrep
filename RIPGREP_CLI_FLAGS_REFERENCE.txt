ENUMS & MODES
================================================================================

SEARCH MODES (SearchMode enum)
  Standard              - Default: find and print matches
  FilesWithMatches      - Show file paths with matches (-l)
  FilesWithoutMatch     - Show file paths without matches (-L)
  Count                 - Count matching lines per file (-c)
  CountMatches          - Count all matches per file (--count-matches)
  JSON                  - JSON Lines format (--json)

CASE MODES (CaseMode enum)
  Sensitive             - Default: case-sensitive matching
  Insensitive           - Case-insensitive matching (-i)
  Smart                 - Auto case-insensitive for lowercase (-S)

REGEX ENGINES (EngineChoice enum)
  Default               - Rust regex engine (default)
  Auto                  - Auto-select engine (--auto-hybrid-regex, deprecated)
  PCRE2                 - PCRE2 engine (-P/--pcre2)

BINARY MODES (BinaryMode enum)
  Auto                  - Skip binary files (default)
  SearchAndSuppress     - Search but suppress matches (--binary)
  AsText                - Treat as text (-a/--text)

BUFFER MODES (BufferMode enum)
  Auto                  - Auto-select based on tty (default)
  Line                  - Line buffering (-n/--line-buffered)
  Block                 - Block buffering (-b/--block-buffered)

ENCODING MODES (EncodingMode enum)
  Auto                  - BOM sniffing + UTF-8 default
  Some(Encoding)        - Force specific encoding (-E/--encoding)
  Disabled              - Raw bytes, no detection (--no-encoding)

MMAP MODES (MmapMode enum)
  Auto                  - Heuristic-based (default)
  AlwaysTryMmap         - Force memory maps (-U/--mmap)
  Never                 - Never use memory maps

SORT MODES (SortModeKind enum)
  Path                  - Sort by file path (--sort)
  LastModified          - Sort by modified time (--sort modified)
  LastAccessed          - Sort by access time (--sort accessed)
  Created               - Sort by creation time (--sort created)

COLOR CHOICES (ColorChoice enum)
  Never                 - No colors (--color never)
  Auto                  - Auto-detect (default)
  Always                - Always color (--color always)
  Ansi                  - Force ANSI (--color ansi)

LOGGING MODES (LoggingMode enum)
  Debug                 - Debug messages (--debug)
  Trace                 - Detailed trace messages (--trace)

SPECIAL MODES (SpecialMode enum)
  HelpShort             - Condensed help (-h)
  HelpLong              - Full help (--help)
  VersionShort          - Version string (-V)
  VersionLong           - Detailed version (--version)
  VersionPCRE2          - PCRE2 version (--pcre2-version)

GENERATION MODES (GenerateMode enum)
  Man                   - Generate man page (--generate man)
  CompleteBash          - Bash completions (--generate complete-bash)
  CompleteZsh           - Zsh completions (--generate complete-zsh)
  CompleteFish          - Fish completions (--generate complete-fish)
  CompletePowerShell    - PowerShell completions (--generate complete-powershell)
